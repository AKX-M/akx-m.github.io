У нас другой прибамбас был: сопровождали Ми-24, по прибору 300-310 в МК, подвеска по 6хБ-8 и по 2 ПТБ-800, ну и петляли, потому как «полосатые» всё равно медленнее шли. Высота 700, справа «сварка», ввод с перегрузкой 3, отработали, вывод 150 м. Никакой другой самолёт такого сделать бы не позволил!

## Код для расчёта дальности

```python
def calculate_range(V, C, L_D, m_start, m_finish):
    import math
    return (V / C) * L_D * math.log(m_start / m_finish)

# Пример расчёта для Су-25
V = 750  # км/ч
C = 1.05  # кг/(кгс·ч)
L_D = 8.5
m_start = 17600  # кг
m_finish = 9000  # кг

range_km = calculate_range(V, C, L_D, m_start, m_finish)
print(f"Дальность полёта: {range_km:.0f} км")
